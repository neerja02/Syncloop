# Syncloop

This repository holds two projects:

| Folder | What it is |
| --- | --- |
| [`kinwell/`](kinwell/) | Kinwell, the full family health assistant app (Next.js). See `kinwell/GETTING-STARTED.md`. |
| [`kinwell-ui/`](kinwell-ui/) | Kinwell's patient UI as a standalone React + Tailwind + Vite project with a working demo. See `kinwell-ui/README.md`. |

Quick preview of the UI demo:

```bash
cd kinwell-ui
npm install
npm run dev   # http://localhost:5173
```
